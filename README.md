# Fibonacci Series Generator

## 📌 Project Description

This project is a simple Python program that generates the Fibonacci series for a user-specified number of terms. Each number in the series is calculated by adding the two preceding numbers.

It is a beginner-friendly project designed to practice Python fundamentals, including variables, loops, user input, and arithmetic operations.

## ✨ Features

- Generates the Fibonacci series for a given number of terms.
- Accepts user input to determine the series length.
- Uses a simple and efficient iterative approach.
- Displays the output in a single line.
- Easy to understand and suitable for Python beginners.

- A code editor or terminal to run the program

No external libraries or additional packages are required.

## 🚀 Usage

Run the program using the following command:

```bash
python fibonacci.py
```

Enter the number of terms when prompted. The program will generate and display the Fibonacci series.

*Note: Depending on your system configuration, you may need to use `python3 fibonacci.py` instead.*

## 💻 Example

**Input:**

```text
Enter the number of terms: 8
```

**Output:**

```text

```
